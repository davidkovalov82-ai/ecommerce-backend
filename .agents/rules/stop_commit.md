## Git действия

Изпълнявам Git commit и push лично.

Агентът може да:
- чете Git историята, status и diff;
- редактира файлове и изпълнява проверки;
- предлага commit съобщение и команди, които аз да изпълня.

Без изрично разрешение за конкретното действие агентът не трябва да:
- добавя промени в staging чрез git add;
- създава или променя commits;
- изпълнява git push;
- създава, обединява или затваря pull requests.

Забраната важи и за действия чрез MCP, GitHub API или други инструменти.

„Реализирай задачата“, „готово“ и „продължи“ не означават разрешение
за commit или push.

След реализацията остави промените локално, представи кратко описание
и резултатите от проверките. Аз ще прегледам и публикувам промените.
